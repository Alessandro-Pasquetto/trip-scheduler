# Trip Scheduler

A collaborative web application for planning trips and organizing activities with real-time synchronization.

## Features

- Create and manage trips
- Calendar and daily schedule
- Add and organize activities
- Invite collaborators
- Role-based permissions (`OWNER`, `EDITOR`, `VIEWER`)
- Real-time updates between collaborators

## Tech Stack

### Backend
- Java 21
- Spring Boot
- Spring MVC
- Spring Data JPA
- Hibernate
- REST API

### Frontend
- Thymeleaf
- JavaScript
- HTML
- CSS

### Real-Time Communication
- WebSocket / STOMP

### Database
- PostgreSQL
